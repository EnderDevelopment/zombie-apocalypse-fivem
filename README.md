# Zombie Apocalypse

Zombie Apocalypse is a FiveM resource that simulates a zombie apocalypse in the game Grand Theft Auto V. It spawns zombie peds around the player, making them hostile and aggressive. The resource is designed to create a survival challenge where players must evade or fight the zombies to survive.

## Install

1. Download the resource files.
2. Place the resource folder in your FiveM server's `resources` directory.
3. Add the following line to your `server.cfg` file:
   ```
   ensure ZombieApocalypse
   ```
4. Restart your FiveM server.

## Use

1. Start the FiveM server.
2. Connect to the server as a player.
3. The zombie apocalypse will begin automatically, with zombies spawning around you.
4. Survive the zombie apocalypse by evading or fighting the zombies.
